=== macOS App Store (limit 4000) ===
xLights 2026.19 - October 23, 2026

New
- Bars: a new Custom direction with an Angle slider moves the bars in any direction.
- The Pictures effect can use SVG images, drawn sharp at the model's size.
- Colour buttons preview the colour live while the colour picker is open, and Cancel restores the original.
- Palette menu: "Update Only Colors" applies just the palette colours to the selected effects.
- Find Possible Source Effects is available from any view.
- Tools > Generate Moving Head Effects builds moving head effects from bars and sections timing tracks.
- Faster renders for sequences with large models or groups set to Render Disabled.
- LOR S5/S6 import: effects land on the matching strands, tiers and columns of the model, custom motion rows can be mapped to submodels or groups, sketches import as SVG pictures, singing faces get lip-sync timing tracks and Faces effects, and many more LOR effects come across.
- Import Effects can convert unsupported videos during the import.
- Pin favorite show folders and switch to them from File > Favorite Show Folders.
- "Promote to Base Show Folder" copies models, groups, 3D objects and controllers into the base show folder and links them.
- Batch Render and FPP Connect show a progress window with each sequence's and controller's result and the time left.
- The Faces, States and SubModels "Import From Model" pickers have a filter box.
- FPP controllers: the new LOR Enhanced serial protocol, and models on USB serial adapters plugged into the controller.

Changed
- SuperStar import scales pictures with the rest of the imported effects by default.
- Help > Forum opens the xLights board on the Falcon Christmas forum.

Fixed
- Some shaders rendered as random noise, and shaders on very large buffers crashed.
- Bars gradients picked up extra hues with non-Normal layer blending.
- Chroma Key turned uncovered areas black, hiding the layers below.
- Fixed crashes in the Butterfly and Music effects, and on very large model group buffers.
- Model groups in a near-perfect row could render very slowly.
- Switching audio tracks during playback now moves playback to the new track.
- Display Elements Show All / Hide All now stick for timing tracks.
- Package Sequence could leave out media used by effects added since the sequence was opened.
- Imported media is no longer reported as relocated on the next open.
- SuperStar and LOR S5/S6 import: overlapping effects, overlay mixes, bar and spiral speeds and several colour conversions are fixed.
- Layout: fixes for Circle, multi-string Cube and multi-layer arch models, older DMX models failing to load, Align Front/Back depth, Model Sets in base show folders, Terrain editing and Add Object in 3D.
- Model groups that contain each other no longer crash the Layout tab.
- Controller visualizer: moving models no longer breaks a port's chain.
- FPP Connect: faster startup when controllers are offline, no stray password prompts, no repeated re-upload of unchanged sequences, inactive controllers set by hostname, and ESPixelStick uploads and discovery.
- LOR output now behaves like FPP's, fixing stuck channels, wrapped units and lag.
- Videos the hardware decoder can't handle switch to software decoding once, and small videos are no longer squashed.
- The system colour picker no longer shifts the chosen colour.
- FPP Connect works when the system temporary folder isn't writable.
- The app no longer freezes while a 3D mesh downloads from iCloud.
- Fixed a large number of crashes, including in timing tracks, the waveform, Search, Effect Presets, the Assist panel, Layout undo/redo, show folder switching, controller discovery and upload, damaged FSEQ and render cache files, and closing a sequence while audio plays.
