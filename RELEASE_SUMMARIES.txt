=== macOS App Store (limit 4000) ===
xLights 2026.20 - November 12, 2026

New
- Faster rendering of many effects, including Shockwave, Color Wash, Bars, Spirals (about 2x), Fan, Galaxy, Morph and Snowflakes, and of animated sub-buffers on large models.
- Spirals: a new Reverse 3D option chooses which edge of the 3D fade leads.
- Custom value curves keep points placed at half steps instead of shifting or merging them.
- Import Effects: preview the vendor's model next to yours, and sort both mapping lists by Name or Master View.
- Bulk Edit: Edit Properties changes a model type's properties on every selected model of that type at once.
- SubModels: Symmetrize (Rotational) is back on Circle, Star, Wreath and Spinner models.
- Media Manager: Re-embed from Disk refreshes an embedded file from its copy on disk.
- Imported From sequences can be edited in Sequence Settings > Meta Data.
- The Visualizer warns when many models are hidden because their preview is Unassigned.
- Bulk Controller Upload: Select All, a filter box, multi-row checking and Invert Selection.

Changed
- A single click on the Layout show folder footer opens the Directories dialog.
- Plasma and Butterfly can differ by one level on a few channels between Intel and Apple Silicon Macs.

Fixed
- Effects: fixes for Guitar, Faces blinks, VU Meter, Bars highlights, Single Strand, Galaxy, Ripple, Snowstorm, Text, Video, Moving Head paths and masked transitions on multi-light nodes.
- Butterfly, Plasma, rotation and zoom render the same with GPU rendering on and off.
- Custom and Cube buffer styles, rotated buffers and Rotate 90 Flip transforms keep every light inside the buffer.
- Value curves: wrapped curves, Sine reverse, .xvc import with a negative minimum, and lost points are fixed.
- Duplicating an effect with Override Timing, and linking an effect to a symbol, no longer wipe settings.
- Effect grid: Shift+scroll keeps the selection, and Ctrl+Left/Right moves several effects as a group.
- Timeline tags no longer carry over to the next sequence.
- Timing and audio: lyric, SRT, Audacity and ElevenLabs import fixes, and better tempo, pitch and key detection.
- Stem separation uses much less memory.
- Sparse FSEQ files with more than 255 ranges no longer lose channels.
- Import: many fixes to SuperStar, Vixen 3, LOR, HLS and Papagayo import; the SuperStar dialog opens quickly on large layouts.
- Import Effects: matrix faces from the base show folder are kept.
- Package import keeps face colours, and embedded media no longer shows duplicate copies.
- Layout: Poly Line channels and light spacing, single-light arches, model start corners, poly line scaling and model groups matching by name prefix are fixed.
- DMX: moving head preview and channel names, servo offsets shrinking on save, and several DMX model crashes are fixed.
- PWM ports drive the right channels and show the right colour labels.
- Controllers: copying and editing controllers keeps their settings, and ArtNet discovery finds every universe.
- FPP Connect: no longer uses a full CPU core while waiting, plus fixes for capes, virtual matrices, playlists, ESPixelStick and older FPP versions.
- Falcon, WLED, ESPixelStick, HinksPix, J1Sys, Minleon, Pixlite and other controller uploads no longer crash on unexpected replies.
- Automation and xlDo fixes, including saveSequence reporting failures.
- Dialogs no longer open on a monitor that is disconnected.
- Fixed a large number of crashes, including zooming after replacing the song, lyric search, Layout undo, empty meshes, damaged layout, model and settings files, and corrupt .fseq files.

=== Windows Store (limit 1500) ===
xLights 2026.20 - November 12, 2026

New
- Faster rendering of many effects; Spirals is about 2x faster.
- Spirals: a Reverse 3D option.
- Import Effects: preview the vendor's model beside yours.

- Sparse FSEQ files no longer lose channels.
- Many SuperStar, Vixen, LOR and timing import fixes.
- DirectX video: small videos and Maintain Aspect Ratio fixed.
- The window no longer sticks between monitors with different scaling.

- Fixed many crashes.
