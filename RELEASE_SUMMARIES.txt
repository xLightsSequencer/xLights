=== macOS App Store (limit 4000) ===
xLights 2026.16 - August 24, 2026

New
- Print Layout is now a full print-preview dialog: pick a preview or the whole layout, set the render resolution, choose which labels are shown (with adjustable size and color), and optionally invert colors before printing. The "Show Names" and "Show Start Channel" checkboxes moved into this dialog.
- Layout: right-click a model and choose "Wire to Closest Controller with Open Port" to auto-assign it to the nearest controller with enough open pixel ports for all its strings.
- The Ripple effect can trigger a new cycle from a timing track, matching Shockwave.
- Lyric phrases and words can now be duplicated.
- Generate Custom Model can capture from a USB webcam and save the result as a custom model file.
- The scroll wheel and trackpad adjust sliders and dropdowns once the control is clicked or focused.
- Export House Preview Video lets you choose the output resolution.
- Custom models gain a Background Image Transparency setting, so props behind the background image show through it.
- Export Models now counts bulbs per node, so shadow and overlapping models are counted once, dumb string types are counted correctly, and DMX fixture channels are no longer counted as bulbs; new totals rows reconcile the channel counts.
- FPP string capes now offer every pixel protocol FPP can actually drive on them, uploaded per port, and Falcon v4 smart receivers can be selected on any string cape FPP drives itself.
- Opening a sequence stored outside the show directory now warns first.
- Crash reports include a recent-activity trace so problems can be diagnosed without debug logging.

Improved
- Opening a sequence with embedded images no longer searches the disk for them, so it no longer spends time re-downloading files evicted to iCloud.
- A sequence referencing a missing picture no longer re-checks for it on every frame, which slowed rendering badly on cloud-backed show folders.

Fixed
- The Ripple effect rendering incorrectly since 2026.15, the Text effect rendering inconsistently, and the Single Strand FX effects blanking part of the model on their first frame.
- Effect editing: multi-row pastes landing on the wrong row, locked effects duplicating when dragged, effect times corrupting after a drag-past-and-resize, a Custom value curve copying the prior effect, and pasting onto a group expanding it.
- Import Effects: picking a color no longer clears that row's mapping.
- Replace Model now removes the source model and keeps the target's aliases; Remove From Group takes a model's submodels with it.
- Crashes starting playback after a pause or audio device change, and a render crash that could leave the app frozen instead of reporting it.
- A crash using the Add Controller button on the Layout tab, and many other crashes across the sequencer, layout editing, model definitions, and sequence import.
- Controller uploads and the controller list no longer stall when a proxy hostname cannot be resolved, and FPP Connect no longer resets FPP settings that xLights does not manage.

=== iPad App Store (limit 4000) ===
xLights 2026.16 - August 24, 2026

New
- Jukebox: link numbered buttons to effects and tap to select and play them, matching the desktop; buttons saved in the sequence work on both platforms.
- Show-folder backup and restore: back up the show's sequences and configuration into a timestamped Backup folder (the same format the desktop writes, so backups restore across both), with optional backup on open, automatic backup before autosave recovery, and a Restore Backup sheet.
- Drag out a region of the grid to select a block of cells, and long-press empty grid space to paste, fill with random effects, or drop in the armed effect.
- Drop an image, video, Glediator or shader file onto the grid to create the matching effect at that spot.
- Press T to drop a timing mark at the play marker while the sequence plays, and S to split the mark under it.
- Lyric breakdown can run on a single word or just the selected marks.
- Effect presets can be exported and imported as .xpreset files, so a preset library moves between iPad and desktop.
- Layout changes are autosaved and offered back after a crash or forced close.
- Previews can be renamed and deleted, and the Layout Editor gains the House Preview's viewpoint menu.
- Import models, groups and viewpoints from another show, and export several models to a single file.
- The controller visualizer can work on a whole port at once: move or remove a port's models and set its smart remote.
- Controller output settings can be edited for every ethernet protocol, including DDP, ZCPP, OPC and Twinkly.
- Light Test gains Groups and Outputs targeting plus a filter box.
- Check Sequence results can be exported as an HTML report.
- Models in the Master View can be dragged into a new order.
- Long-press the render button to see per-model render progress.

Improved
- The sequencer grid and house preview do much less work per frame, so dragging and scrolling stay smooth on large sequences, with much lower CPU and battery use.
- The sequence picker no longer stutters on show folders stored in iCloud Drive.
- Controller discovery now probes the controllers already in the show, so controllers on another subnet or behind a proxy are found, and password-protected controllers ask for the password.

Fixed
- Views are saved again - view edits were previously lost on relaunch.
- A newly dropped effect starts with the desktop's default palette, and State and Faces effects start on their first state or phoneme instead of blank.
- Effects that follow a timing track or another model re-render on their own when what they follow changes.
- Changing a sequence's frame interval now moves effects onto the new interval, as the desktop does.
- More operations can be undone, including Breakdown Words and Convert Data to Effects.
- The lights blank when playback stops instead of holding the last frame, and playback follows the audio track picked in the waveform.
- A crash when changing the show folder while a sequence was rendering, and crash reports now carry a full backtrace so problems get fixed faster.

=== Windows Store (limit 1500) ===
xLights 2026.16 - August 24, 2026

New
- Print Layout is now a print-preview dialog: pick a preview or the whole layout, choose resolution, labels and colors.
- Layout: right-click a model to wire it to the closest controller with enough open ports.
- Ripple can trigger a new cycle from a timing track; lyric phrases and words can be duplicated.
- Generate Custom Model can capture from a USB webcam, and the camera scan option works again.
- FPP string capes offer every pixel protocol FPP can drive, uploaded per port.

Improved
- Sequence playback no longer runs below the configured frame rate.
- Renders with many video effects no longer hang with the DirectX11 decoder, and Intel QuickSync hardware decode now actually engages - about 3x faster than software.

Fixed
- Ripple, Text and Single Strand FX rendering problems, effect paste/drag/resize bugs, and a Custom value curve copying the prior effect.
- Replace Model and Remove From Group fixes, plus many crash fixes across the sequencer, layout and playback.
- A startup crash on machines without OpenGL drivers, and controller uploads stalling on unresolvable proxy hostnames.
