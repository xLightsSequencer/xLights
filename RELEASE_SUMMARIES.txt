=== macOS App Store (limit 4000) ===
xLights 2026.21 - November 24, 2026

New
- Much broader Undo: timing track add/delete/rename/reorder, model add/remove/reorder in the sequence, timing and effect imports, Shift Effects, Convert Data To Effects, Promote Node Effects, effect symbols, tags, song structure, sequence faces and every Media Manager edit can now be undone, each as one step.
- Shared show folders: changes someone else saves to the layout, controllers or effect presets are merged with yours instead of overwritten. You only choose where you both changed the same thing, and their changes are brought into the open show once playback stops.
- Shared show folders: you are warned before overwriting someone else's saved changes, warned when opening a sequence someone else has open, and the status bar shows who else is editing the layout or controllers.
- Autosaves in a shared show folder are kept per computer, and restoring one no longer discards changes someone else saved since.
- Opening a sequence saved before models were renamed in the layout renames its rows to match instead of asking about missing models.
- Conflicted copies left by Dropbox, iCloud, OneDrive, Google Drive or Syncthing can be merged back into the layout, controller and preset files.
- Show files are saved in one step, so a crash or sync client never sees a half-written file.
- Lyrics: Generate AI Image for Phrase adds a Pictures effect with an AI-generated image for the phrase.
- Custom Model: drag with the middle mouse button to pan the grid.
- Layout: Esc exits the active model drawing tool.
- Controller Visualiser: drag a port's label to move all its models to another port, or back to the model pool.
- FPP Connect: the upload log shows whether each controller's media was uploaded, already up to date, or not found, and the upload window has a resizable Completed list.
- ILightThat controllers: upload grouping, zig zag and start/end null pixels.

Changed
- Controller Open / Open Proxy buttons stay enabled while outputting to lights.

Fixed
- Many Undo fixes: effect settings panel changes are restored exactly, removing a layer brings back its name and effects, Split Effect and Paste as Layers undo in one step, and Undo no longer changes the wrong effect after some edits.
- Bulk editing a DMX channel slider could clear value curves on other channels.
- SingleStrand with a 6-colour palette could crash and left out colour 5.
- Layered Arches with an Inside start rendered Strand effects on the wrong nodes.
- Moving Head Adv: position zones now apply when the effect is on a group, and the zone indicator sits upright around the yoke again.
- Shift Effects no longer moves locked effects.
- Select Effects, Effect Preset previews, AI Lyrics from Audio and AC mode off over a locked effect are fixed.
- Media: Pictures assist pixel edits to embedded images are saved, Extract All renames SVG, shader and text media, and renaming embedded media works.
- SubModels: Import Custom Model Overlay honours the chosen position and keeps the outline's shape.
- Print Layout prints what the preview shows.
- LOR S5, LMS and HLS import fixes.
- FPP Connect: playlist, status and discovery fixes, and a crash when an FPP asks for a password.
- Falcon and HinksPix upload and export fixes.
- Fixed crashes in bulk editing, Generate Custom Model, layer changes during rendering and starting playback, and a hang when closing on a busy Mac.

=== iPad App Store (limit 4000) ===
xLights 2026.21 - November 24, 2026

New
- Much broader Undo and Redo: timing imports, new timing tracks (including AI lyrics, tempo, chords and onsets), renaming and deleting timing tracks, moving rows, tags, sequence faces, song structure, Import Effects, SuperStar import, Import Lyrics, effect symbols and every Media Manager edit can now be undone, each as one step.
- Song structure boundaries can be dragged in the waveform strip.
- Shared show folders: changes someone else saves to the layout, controllers or effect presets are merged with yours instead of overwritten. You only choose where you both changed the same thing, and their changes are brought into the open show once playback or a drag ends (can be turned off in Settings).
- Shared show folders: you are warned before overwriting someone else's saved changes, warned when opening a sequence someone else has open (open anyway or read-only), and the layout editor shows who else is editing.
- Autosaves in a shared show folder are kept per device, and restoring one no longer discards changes someone else saved since.
- Opening a sequence saved before models were renamed in the layout renames its rows to match.
- Conflicted copies left by iCloud, Dropbox and other sync services can be merged back into the layout, controller and preset files.
- Show files are saved in one step, so a crash or sync never sees a half-written file.

Fixed
- Dragging an effect setting slider or typing a value is one undo step.
- Undo of a large step such as pasting many effects now fully reverts it.
- Undo and Redo after Promote Node Effects, Convert Data to Effects, Breakdown Phrase and Breakdown Word(s) work correctly.
- A deleted model no longer comes back after saving the layout.
- SingleStrand with a 6-colour palette could crash.
- Layered Arches with an Inside start rendered Strand effects on the wrong nodes.
- Moving Head Adv: position zones now apply when the effect is on a group.
- Fixed a crash starting playback and a hang when closing on a busy device.
